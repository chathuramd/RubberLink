# Troubleshooting

- Prisma error: run `npx prisma generate`.
- MySQL error: create database and check `DATABASE_URL`.
- Frontend cannot call API: set `VITE_API_URL="http://localhost:5000/api"` and restart Vite.
- ML unavailable: backend still allows manual final grade.
- TensorFlow install issue: use Python 3.10 or 3.11.
